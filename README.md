# dhistack.ai

Marketing site for **dhistack.ai** — an AI-native software house building custom software, mobile apps, CRM platforms, interactive web, AI agents and data/cloud solutions.

> *dhī* — the Sanskrit word for intellect & insight. We stack that intelligence into everything we build.

## Contents
- `index.html` — the main one-page website (self-contained: HTML, CSS, JS).
- `motion-lab.html` — interactive showcase of the animation patterns.
- `backups/` — earlier design versions kept for reference.

## Design
- **Palette:** "Vrishchika Twilight" — midnight indigo, oxblood, illumined gold, ember accent.
- **Signature motion:** particle-morph hero, portal page transitions, decode-reveal titles.
- No build step, no dependencies — open `index.html` in any browser.

## Deploy
Static site. Deploys as-is to Cloudflare Pages, Netlify, Vercel or GitHub Pages.
